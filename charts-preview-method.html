What a number is

A chart position is stored with the chart name, the source name, and the chart date. If the date or the source was left blank, the page says Data unavailable. A month with no day is shown as that month. It does not guess a day.

YouTube views come from a daily pull of the YouTube Data API. The pull runs only when YOUTUBE_API_KEY is set. If the key is missing, or the search does not return one exact title and artist match, the value is Data unavailable.

Apple Music position comes from the free Most Played songs feed. The song counts only when the title and artist match that feed. If the feed is down, or the song is not in it, the value is Data unavailable.

Spotify and TikTok are Coming soon. They are not estimated.

The AI label is AI only when the stored source says the artist disclosed that use publicly. If that disclosure is missing, the label is Unknown. A human seed row stays Human. Breaking Rust and Cain Walker stay Unknown, with the Billboard virtual act note on the source.

A song whose seed marks the genre out of scope is tagged Benchmark.

The daily job is /api/charts-preview/cron. A correction form note is saved and does not change a number by itself.
