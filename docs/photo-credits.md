## World map geometry

`assets/world-countries.json` is a simplified outline of countries for the analytics map. The shapes come from Natural Earth 1:110m cultural vectors, which are public domain: https://www.naturalearthdata.com/about/terms-of-use/

The file was projected and simplified locally from the `world-atlas` 2.0.2 countries-110m topology (ISC license, https://github.com/topojson/world-atlas). The page does not call a tile server and does not ship that library.
