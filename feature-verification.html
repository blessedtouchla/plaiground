Featured-artist help

DM DistroKid with your UPC

When DistroKid asks a featured artist to verify a name, their help page says to send a DM to @distrokid on X or Instagram, and to include the release UPC.

This page does not send the message for you, and it is not an official DistroKid tool. It opens X with the message already typed, or copies the same message so you can paste it into Instagram. DistroKid makes its own decision. We cannot promise they will accept the DM.

Message: Verifying for UPC …

DM DistroKid on X

Before you hit send

  • Use this when DistroKid has asked for verification. Their help page says you do not need to contact them before they ask.
  • Send the DM from an established X or Instagram account. DistroKid says a brand-new account will not work.
  • The featured artist should send the DM, from their own account, not from the primary artist's account.
  • On a phone, the prefilled X message usually appears. On a desktop browser, the text box can show up empty. If that happens, paste the copied message and send it yourself.
  • DistroKid also accepts a photo of a driver's license or passport, with personal details blocked out, plus the UPC. That path is on their help page, not on this screen.

Read DistroKid's own instructions: Verifying an Artist Name When DistroKid Requires It.

You can also pass this page to the featured artist with the UPC already filled in, by adding ?upc= and the digits to the link.
